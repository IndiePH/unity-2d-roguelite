# Feature Specs

Owned child docs for feature detail. Mother docs link here; they do not duplicate the full design.

Create a spec when a feature is about to be built or a design choice would change implementation, and `GDD.md` is not enough. Name the player action, the rule, files it may touch, and acceptance criteria.

Conventions (naming, ownership, frontmatter, status): [../README.md](../README.md).
