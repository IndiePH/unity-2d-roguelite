# Decisions

Owned child docs for choices that should not be re-litigated every session.

Write a decision when the team approves a choice not already settled in a mother doc. Record the choice, alternative rejected, and why. Then update the relevant mother summary.

`accepted` decisions are authority; do not reopen without new facts.

Conventions (naming, frontmatter, supersession): [../README.md](../README.md).
